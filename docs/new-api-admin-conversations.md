# 管理员查看 Forest 用户聊天记录

## 入口与范围

更新 Go 后端和管理端静态产物后，进入 **后台 → New API 接入 → 用户聊天**。

- 查看普通 AI 对话、角色聊天及独立分支，不是“AI 运维”的管理员/员工会话。
- 按用户 ID、完整邮箱、标题关键词、模型、会话类型、创建时间组合筛选；条件为 AND。时间选择精确到分钟，按当前浏览器时区展示，开始包含、结束不包含。
- 列表显示归属、角色名、模型、消息数量、创建时间和最近消息时间，不批量下载正文。
- “查看聊天”默认获取最新 100 条，按从旧到新展示并定位到最新消息；“加载更早消息”向前分页，加载后保持当前阅读位置。
- 用户设定与角色快照默认折叠。快照是创建会话时使用的设定，不随后来编辑/删除角色库条目而变化。
- 只有仍具管理员权限、未封禁的账号可访问；员工、普通用户、撤销的登录和仅用于门户的令牌不能调用这些接口。

这是只读功能，不提供编辑、代发、重试、删除、恢复会话或导出操作。查看不会请求上游模型、扣余额、修改生成中/失败消息状态，也不参与支付配置。

## 数据在哪里

数据在 Forest 后端 PostgreSQL，不在本地浏览器，也不是去 New API 站点读取：

| 表 | 内容 |
| --- | --- |
| `v2_newapi_chat` | 会话、归属、模型、用户设定及角色快照 |
| `v2_newapi_chat_message` | 用户消息、模型回复、完成状态及时间 |
| `v2_newapi_character` | 用户保存的角色库，不代替会话内历史快照 |
| `v2_newapi_chat_request` | 请求去重/计费防重放记录；不是正文备份 |

按本次用户确认，**删除语义不变**：用户主动删除会话后，会话及其消息物理删除，管理员不能在此查到或恢复正文。已创建的分支为独立会话，删除父会话不会连带删除分支中已复制的内容。请求去重记录继续保留，防止同一请求被再次付费提交。

“账号已删除”标签只表示当前用户表没有对应账号，不代表这条会话已删除。既有用户删除路径没有级联清理 AI 会话时，仍然存在的记录会用原用户 ID 展示，邮箱标为不可用。

当前未设置聊天自动清理周期，不沿用订阅访问日志的 7 天期限。本次没有新增隐藏正文备份或已删除会话回收站。

## 接口

路径前缀为 `/api/v1/<后台安全路径>`，仅接受 `Authorization` 请求头与 GET；未知、重复或无效参数直接返回错误。

| 接口 | 参数 |
| --- | --- |
| `/new-api/conversations` | `current`（1）、`page_size`（20，最多100）、可选 `user_id` / `email` / `keyword` / `mode` / `model` / `start_at` / `end_at` |
| `/new-api/conversations/detail` | 必填 `id` |
| `/new-api/conversations/messages` | 必填 `id`；可选 `before_id`、`page_size`（100，最多200） |

时间为 Unix 秒。`email`、`model` 为精确匹配，标题按字面子串匹配，`%`、`_` 不是通配符。详情和消息分页需重新鉴权，服务层再次核对实时管理员状态；每次读取使用只读、可重复读事务，防止同一次响应的计数、归属和正文状态混杂。

接口仅返回明确选择的聊天字段，不附带用户密码、账号令牌、支付配置、上游凭据或请求哈希。角色任意扩展不返回。用户若自行把敏感内容写入消息或角色正文，管理员阅读正文时也能看到；这不是自动脱敏保证。

正文与角色内容按纯文本渲染，不执行 HTML、脚本、工具声明或外部图片；响应禁止缓存，前端不持久保存到 localStorage。切换/关闭详情时中止旧请求并校验请求序号，防止迟到响应串会话。

## 发布与验证

本轮只在本地实现和验证。前端只更新 Forest 用户页面不能增加这个后台入口，需要发布本仓库 Go 后端与 `public/assets/admin-new` 管理端产物；数据库启动迁移只补充管理员全站排序索引，不改正文或删除流程。

本轮本地验证（2026-11-11）：

- 7 项管理员服务回归，及完整 `newapibridge` PostgreSQL 测试（`-race`）通过；测试使用独立临时数据库/分区与虚构用户，没有读取真实聊天或付费调用。
- New API HTTP 鉴权、参数、错误与现有接口回归通过，含管理员/员工/普通用户/撤权/门户令牌矩阵；Go 服务二进制构建通过。
- 管理端相关 36 项测试、TypeScript 检查、生产构建与 2 项产物契约测试通过。
- Chromium 桌面及 iPhone 尺寸模拟的只读浏览器验证通过：筛选、分钟时间边界、最新消息定位、加载更早消息、关闭/切换的迟到响应、错误与空状态、角色快照纯文本、员工无入口。手机使用 Chromium 设备模拟，不等同于真实 iOS WebKit 验收。
- 浏览器接口全部为虚构数据，未登录线上管理员、未读线上用户消息。产物已在工作区重建，但没有推送 GitHub 或上线部署。

本地验证日志与截图在 `/tmp/forest-admin-chat-20261111/`，不是产品数据存储位置。构建保留既有字体资源解析及大体积单文件包提示，不影响本轮通过，也没有为了消除警告拆坏管理端的单文件加载契约。
