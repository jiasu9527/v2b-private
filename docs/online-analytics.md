# 在线用户分析

管理员从仪表盘点击「在线人数」进入 `/<admin_path>/dashboard/online`。详情页不新增一级菜单，员工工作台不开放该页面或接口。

## 人数口径

- **当前在线**：`v2_user.t` 在最近 600 秒内有流量活动的用户，与仪表盘原有口径一致；不是实时 TCP 连接数。
- **24 小时内在线**：最近 86400 秒有流量活动的去重用户。
- **7 天内在线**：最近 604800 秒有流量活动的去重用户，包含最近 24 小时，不是每日人数相加。
- **当前在线占比**：当前在线用户 / 全部注册用户。
- **地区分布**：仅当前在线用户，每人最多计入一个国家／地区、一个中国省级地区及该省下的一个城市；各地区 API 占比均以全部当前在线用户为分母，包含地区未知的用户。城市详情另展示以本省在线人数为分母的占比。

以上统计使用一次 PostgreSQL 查询快照。既有 `v2_user.t` 可直接支持 24 小时与 7 天统计，升级不需要等待积累一周，不会额外记录每次访问日志。

## 地图与位置

世界地图支持缩放，点击中国切换到省级地图，再点击省份或省份明细表的名称可查看城市地图、城市人数和前八名排行。支持返回全国及切换省份，自动刷新保留当前层级。

点击城市地图、城市名称或明细表人数，可打开该区域当前在线账号列表。列表支持分页、精确邮箱／用户 ID 搜索和手动刷新，显示账号、最近流量活动时间、地区及定位说明。国家、省份明细的人数也可打开对应账号；「位置未知」总数及各原因人数可查看相应账号，方便排查。账号列表仅限管理员，不向员工开放，不返回密码、订阅 Token、UUID 或原始 IP。

省内城市使用节点 IP 定位库给出的城市名，不根据省份猜测省会。北京、天津、上海、重庆按直辖市整体展示；没有可用城市边界的地区仅展示范围轮廓，并保留城市明细，不将具体城市人数涂到整个地区。未知城市在列表单列，已识别但未匹配底图的城市也保留在列表和总数中。世界低分辨率底图不能完整绘制所有小地区，这些地区同样不会丢失统计。

省级城市地图是本地静态 JSON，按需从同站点加载，文件名带内容哈希。加载失败可重试，不影响人数表与排行；快速切换省份时旧请求不会覆盖当前地图。

位置使用节点 alive 上报的用户连接 IP，在后端通过本地 ip2region IPv4/IPv6 数据库解析。不向外部服务发送用户 IP，不使用代理节点自身的地理位置，也不使用管理员访问页面的 IP。

每个用户只保留最后一份粗粒度位置摘要（国家、省份及城市名），不在新表保存原始 IP。节点地址兼容纯 IPv4／IPv6、IPv4:端口、[IPv6]:端口及设备标记。多设备和多节点上报时，从仍有效的节点地址中稳定选择可识别位置；无效地址不会覆盖仍新鲜的有效位置，也不会延长该位置的真实观测时间。相同位置最多每分钟更新一次，省内城市变化也及时更新；超过 7 天无报告的摘要由现有每日清理任务分批删除，删除用户时级联删除。

打开统计或账号列表时，后端限频、限量检查已有 `ALIVE_IP_USER_*` 短期缓存，自动补齐缺失或可修复的地区摘要。仅使用仍有效的节点条目并保留原上报时间，避免升级前已有 IP、摘要写入失败或地址格式不兼容造成有 IP 却没有地区。该过程不新增 IP 历史日志，不阻断正常节点上报；缓存已过期则等待新报告。

位置超过 10 分钟、节点未上报、私网／保留地址、离线库未准备或没有匹配结果时，明确显示为未知。已识别国家但未识别省份的用户在省份列表显示「省份未知」。定位覆盖率是已识别国家／地区的人数除以当前在线人数。

IP 位置是网络出口估算，可能受移动网络、运营商或前置代理影响，不是实际 GPS 地址。上线后需要节点的新 alive 报告才能逐渐产生地区数据；只上报流量、不上报用户 IP 的节点，其在线人数正常统计，地区显示未知。

## 安装与升级

标准 `scripts/appctl` 安装／更新构建过程自动运行：

```sh
bash scripts/prepare-ipgeo.sh
```

两个数据库约 48 MB，默认放在 `storage/ipgeo`，不纳入 Git。下载固定上游版本并校验 SHA256，临时文件校验通过后才替换已有文件。网络失败保留已有库且不阻断网站启动；页面显示定位库缺失／部分就绪。补下载后重启后端加载新库。

手动构建、容器部署时，需要显式执行该脚本并将 `storage/ipgeo` 放在后端可读取的持久化目录。也可以给脚本和后端进程同时设置绝对路径环境变量 `FOREST_IPGEO_DIR`。后端默认使用 `PUBLIC_DIR` 上级目录下的 `storage/ipgeo`。

启动时幂等创建 `v2_user_online_location` 表及索引，并给旧表增加 `city_name` 字段；安装 SQL 和升级 SQL 同步包含迁移语句。旧摘要不会猜测或反填城市，需收到新的节点 alive 报告后产生城市分布；在此之前人数仍保留，城市显示未知。

数据库的来源、固定版本及许可证见 `go-api/internal/platform/ipgeo/README.md`；地图来源见 `admin-src/src/assets/maps/README.md`。

## 管理 API

`GET /api/v1/<admin_path>/stat/online`，仅管理员会话可用，响应禁止缓存。未认证或员工／普通用户返回 403，服务不可用返回 503。数据位于 `data`：

| 字段 | 含义 |
| --- | --- |
| `generated_at` / `online_window_seconds` | 生成时间戳／当前在线窗口秒数 |
| `current_online` / `unique_24h` / `unique_7d` | 当前、24 小时、7 天去重用户数 |
| `total_users` / `online_share` | 总用户数／当前在线百分比 |
| `geo_located_users` / `geo_unknown_users` / `geo_coverage` | 已定位、未知人数／覆盖百分比 |
| `countries` / `china_provinces` | `{code,name,users,share}` 数组；国家 ISO2，省份六位行政区码 |
| `china_cities` | `{province_code,code,name,users,share}` 数组；`code` 为省内规范城市名（去末尾“市”“地区”，自治州原名保留），不是行政区码；城市未知时 `code` 为空。每省城市数组包含未知项后与省份人数一致 |
| `unknown_reasons` | `{code,name,users}` 未知原因分组 |
| `geo_database` | `{status,ipv4,ipv6,source,version}` 离线库状态 |

该汇总接口不返回邮箱、用户 ID 或原始 IP。前端每 45 秒刷新，页面隐藏时暂停，可手动关闭自动刷新。请求失败保留并标注上次数据，不把失败显示成零在线。

`GET /api/v1/<admin_path>/stat/online/users`：仅管理员可查看的分页账号列表，响应禁止缓存，沿用汇总的近 600 秒流量活动和地区有效期口径。

| 参数 | 含义 |
| --- | --- |
| `scope` | `all`、`country`、`province`、`city`、`unknown` |
| `country_code` | 国家范围的 ISO2 代码 |
| `province_code` | 省份／城市范围的六位省码；省份范围为空时为省份未知 |
| `city` | 城市范围的规范城市名；空值为城市未知 |
| `reason` | 未知范围可选的原因代码；省略时为全部位置未知 |
| `search` | 精确邮箱或用户 ID，不是模糊搜索 |
| `page` / `page_size` | 页码和每页条数，默认 1 / 20，单页最多 100 |

返回 `data={total,page,page_size,generated_at,online_window_seconds,users}`。每个账号包含 `id`、`email`、`last_seen_at`（最近流量活动时间）、`location_seen_at`（实际位置上报时间）、国家／省份／城市及 `unknown_reason`。人数和分页来自同一查询快照；汇总与列表属于不同请求，实时用户进出时两者可能有变化。

排查「位置未知」时应查看 `unknown_reasons`，不能仅根据汇总人数判断是定位库故障。未收到地址、上报过期、内网／保留地址、格式不合法、定位库缺失及地区未匹配各自单列原因。节点上报了 IP 并不保证离线库包含其地区；不会用节点机房位置、猜测省会或无限沿用旧位置来消除未知。

## 前端发布验证

后台 Go 模板以 `admin.js?v=<文件修改时间>` 加载入口，因此管理端保持单个自包含 JavaScript 包。在线分析页及世界／全国底图同包发布，省内城市地图单独作为静态 JSON 加载。构建时禁止额外 JavaScript 分包或入口的模块依赖，避免分包回引不带 `?v=` 的 `admin.js`，产生两份 React 和重复挂载。若未来需要 JavaScript 拆包，必须同时调整模板与资源版本管理。

回归验证必须使用生产构建和 Go 模板中的带版本参数入口：从仪表盘点击在线人数、切换世界／中国省份／城市、返回后再次进入，以及直接刷新详情页，确认无 React #321 或 `removeChild` 错误。验证地图加载失败、城市未知及直辖市的降级说明。仅运行 Vite 开发页面不能覆盖此部署路径。
