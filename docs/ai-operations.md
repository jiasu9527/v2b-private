# 后台 AI 运维

## 启用

更新 Go 后端与后台静态资源后，使用管理员账号进入 **AI 运维 → 设置**。员工、普通用户不能访问此模块；接口每次重新核对管理员身份，不使用 AI 独立 Token，也不需要 MCP 客户端。

1. 填入支持 OpenAI 兼容 **Chat Completions + tool calling** 的中转地址和 API Key。
2. 地址通常填 `https://relay.example.com/v1`；只填域名会补 `/v1`，也接受完整 `/v1/chat/completions` 地址。自定义前缀应填写到 `chat/completions` 之前。
3. 公网中转必须使用 HTTPS；仅本机回环测试允许 HTTP。服务不跟随重定向，避免 Key 被重定向到其他站点。
4. 模型 ID 每行一个，默认原样提供：
   ```text
   gpt-6.1-sol
   claude-fable-5-1
   deepseek-v4.1-flash
   glm-5.3
   ```
   不自动替换模型；中转必须实际开通对应模型及工具调用。聊天时可以切换模型。
5. 保存并启用后，发送简单的查询请求验证连通性。服务向 `/chat/completions` 请求流式响应，网页通过 SSE 实时显示回复；中转忽略流式参数并返回普通 JSON 时仍可兼容，但只能整段显示。

本模块默认关闭。首次访问自动创建六张 `v2_ai_*` 表并补齐缺少的字段，数据库账号须具备建表、修改表和建索引权限，无需运行整库安装 SQL。请保留稳定的 `APP_KEY`；API Key、SSH 密码、私钥及私钥口令通过由它派生的 AES-GCM 密钥加密保存，修改 `APP_KEY` 后需重新录入这些凭据。

API Key 只写不读，留空保留；**修改中转地址必须重新输入 Key 或明确清除旧 Key**，不会将旧 Key 自动带到新地址。

## 对话显示

- 普通对话文字默认展开，支持粗体、列表、表格和代码块；工具调用、参数、原始结果及操作输出默认折叠，按需展开。
- **Enter 发送，Shift+Enter 换行**；中文输入法选字时不会误发送。
- 待确认操作的状态与审核按钮始终可见；进入审核窗口后完整命令或变更内容展开显示，仍须逐条确认。
- 正在回复时增量显示文字，向上翻阅历史记录不会被强制滚回底部。切换会话或暂时断网不会取消后台任务。

浏览器 SSE 连接约 25 秒自动重连，连接不可用时回退到自动刷新。接口使用 `Authorization` 请求头，返回 `X-Accel-Buffering: no`；若前置代理仍强制缓冲，应为 `session/stream` 关闭缓冲。流式草稿每约 600 毫秒覆盖同一轮次记录，结束后清除，**不会按每个字符或分片新增日志记录**。工具参数必须完整接收且上游明确结束后才可执行，断流不会执行半截工具调用。

## 能做什么

### 自动查询

- 按完整邮箱或 ID 精确查询普通用户套餐、用量等信息。
- 查询套餐订单、节点基本配置及上报状态。
- 查询入口规则、二分叶子组，按邮箱与实际 UA 模拟当前入口匹配。
- 查询已有入口检测、备用 IP 健康与占用、调度和队列概况。
- 查询管理员预先登记的 SSH 服务器列表。

查询结果使用单独的字段白名单，不返回用户密码、订阅 Token/UUID、支付密钥、SSH 凭据、节点安装密钥或 Apple ID 交付内容。一次查询默认 20 条、最多 50 条；结果过长时自动缩小当页条数，并返回实际总数和下一页位置。单条超大规则的嵌套明细会明确标记截断。需按返回位置逐页继续，不应把一页当成全站数据。

### 逐次确认后执行

- 修改指定节点的 `host`、`port`、`show`，不提供任意后台 API 或数据库 SQL 透传。
- 修改入口规则／二分叶子组的入口 `host`，保留 UA 条件、固定用户名单等。合集中的成员不能单独修改，非叶子组不能直接改。
- 发起指定规则的检测；检测结果仍遵循原后台自动化配置，**可能触发现有自动切换／二分逻辑**。
- 在已登记服务器上执行完整 SSH 命令，包括只读诊断、部署节点、修改服务配置。

AI 只能提出操作卡片，**没有批准操作的工具**。页面展示目标、完整命令或配置前后值；管理员逐条核对后点击确认。只读 SSH 状态检查同样需要确认。审批后可继续发送“分析刚才执行结果”，模型会获得动作状态和有限长度输出摘要，不会自动连续执行下一条命令。

动作有效期 15 分钟。审批使用配置快照校验；目标节点、入口条件、固定名单或 SSH 服务器身份发生变化后，旧操作会拒绝执行，应重新分析生成提案。并发或重复批准只会有一次实际执行。

## 登记服务器

进入 **AI 运维 → 服务器 → 登记服务器**：

- 填名称、主机地址、SSH 端口、用户名、密码或私钥。
- “获取主机指纹”只进行握手观察，不使用密码登录，也不会自动信任观察到的指纹。
- 通过可信服务器控制台等独立渠道核对 `SHA256:...` 主机指纹后填写并保存。
- 正式连接必须匹配已保存指纹；不匹配会在认证及命令执行前拒绝。
- 修改主机、端口、用户名或指纹时，旧凭据不会隐式复用；重新填写连接凭据。

不读取面板宿主机的个人 SSH Key、SSH 配置或系统凭据；不会在面板本机 Shell 执行模型命令，只通过登记目标的 SSH 会话发送经确认的原始命令。

部署建议拆成“检查 → 明确配置 → 备份 → 执行 → 验证”多个步骤。单条远程执行最长 120 秒，最多同时执行 2 条 SSH 命令，输出上限 32 KiB。部署中断或连接断开可能已部分执行，标为失败／结果未知后需人工核对，**不会自动重试，也不保证远程回滚**。不要在未核对的脚本中写入凭据，或让命令输出整份秘密配置。

## 会话与数据清理

所有管理员共享全部会话；员工无访问和清理权限。不会另建逐条查询日志，聊天与动作结果本身就是本模块的操作记录。

| 操作 | 删除范围 |
| --- | --- |
| 删除某会话 | 该会话、消息、生成轮次、待确认及已完成操作记录 |
| 清空全部会话 | 所有管理员的会话及其附属记录；保留中转配置和服务器 |
| 重置全部 AI 数据 | 上述全部会话数据 + 中转配置/Key + SSH 服务器配置/凭据；须输入 `RESET_AI_DATA` |

清理仅删除 `v2_ai_*` 模块记录，不删除用户、订单、节点、入口规则，也不会撤销已批准的业务变更。

有远程操作正在执行时，删除该会话或清空／重置会拒绝；等待操作结束或核对中断状态后再清理。正在生成的 AI 对话可以删除，后台会停止后续生成和持久化，不会复活已删除会话。进程意外重启后，超时执行记录显示“结果未知”，不能据此认定远程没有执行。

数据库删除不等于擦除备份、WAL、代理记录或中转提供商已经收到的数据。**聊天文字、业务查询结果、命令以及有限输出会发送到管理员配置的中转站**；中转和模型保留策略由管理员选择的平台决定。本模块只会过滤它已知的 SSH 凭据原文，不保证任意远程输出都没有秘密。

## 容量及接口

- 最多 200 个会话、200 台登记服务器；单会话消息有上限，接近容量时需要新建会话或清理。
- 模型上下文保留最近 10 个完整轮次及最近 10 个动作摘要，超大上下文拒绝发送。
- 最多 4 个并发生成任务，每个会话同时 1 个；每轮最多 6 次工具分析、120 秒。
- 请求携带 `request_id` 做发送幂等，重试同一内容不要换 ID；审批不可重放。
- 所有接口使用既有管理员会话，`Cache-Control: no-store`，不支持匿名或外部模型直接调用。

接口前缀为 `/api/v1/<后台路径>/ai-ops/`：

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET / POST | `config` / `config/save` | 获取无密钥配置 / 保存配置 |
| GET | `sessions`、`session?id=...` | 全部会话 / 消息、轮次及操作详情 |
| GET | `session/stream?id=...` | SSE 实时快照与回复草稿，仅管理员可访问 |
| POST | `session/create`、`chat/send` | 建立会话 / 异步生成（202） |
| POST | `session/delete`、`session/clear`、`reset` | 显式确认清理 |
| GET / POST | `servers` / `server/save` | 服务器列表 / 保存加密凭据 |
| POST | `server/fingerprint`、`server/delete` | 观察指纹 / 版本校验删除 |
| POST | `action/approve`、`action/reject` | 人工确认（202）/ 拒绝 |

## 本地验证

```sh
cd go-api
go test ./...
go vet ./...
go test -race ./internal/aiops ./internal/http

cd ../admin-src
npm run check
node --test scripts/test-*.mjs tests/*.test.mjs
npm run build
```

PostgreSQL 集成测试仅在指定一次性测试数据库时运行；初始化测试库使用安装 SQL，**切勿对真实数据库执行**。核心测试使用 `FOREST_AIOPS_TEST_DSN`，HTTP 集成使用独立空库的 `FOREST_AIOPS_HTTP_TEST_DSN`。模拟中转与本地模拟 SSH 验证加密、精确模型 ID、未确认不执行、并发批准、错误主机指纹、结果回传、取消／清理以及数据不复活，不消耗真实中转额度或连接业务服务器。

### 真实中转兼容性测试（可选）

提供 `FOREST_AIOPS_LIVE_BASE_URL`、`FOREST_AIOPS_LIVE_API_KEY` 后，运行：

```sh
go test ./internal/aiops -run '^TestAIRelayLiveCompatibility$' -count=1 -v -timeout=8m
```

Key 应由临时环境或秘密管理设施注入，不写进源码、测试快照或命令行参数。缺少配置时测试自动跳过；显式启用会消耗少量中转额度。可设置 `FOREST_AIOPS_LIVE_MODELS=gpt-6.1-sol` 只测一个已授权模型；不指定则测试四个默认 ID，不会替换成其他模型。

兼容性测试使用实际的 14 个工具定义，验证只读工具调用、合成工具结果回填、待审批节点变更提案；不会真正调用工具或连接业务数据库、SSH。只输出阶段、HTTP 状态及耗时，不输出 Key 或完整响应。

若还需要验证真实会话和审批持久化，可以额外设置指向**空白一次性 PostgreSQL 测试库**的 `FOREST_AIOPS_LIVE_TEST_DSN`，执行 `go test ./internal/aiops -run '^TestAIRelayLivePostgresFlow$' -count=1 -v -timeout=6m`。该测试只使用 `gpt-6.1-sol`，最多两次中转请求；创建虚构本地节点，核对未审批不修改、仅批准该测试节点一次、结果进入下一轮上下文、删除／重置不影响业务表，随后清理全部测试记录。不登记或连接 SSH，不允许使用真实数据库；测试使用一次性随机 `APP_KEY`，不会保留可解密临时凭据的固定密钥。

### 常见中转错误

- **401**：Key 无效或过期。
- **403**：权限、IP 白名单或中转防火墙拒绝访问。
- **`model_not_found` / `model_not_available`**：当前 Key 所属分组没有该模型，即使中转站其他分组支持也不能调用。后台会明确提示“所选模型在当前 API Key 分组不可用”，不会自动改用别的模型。
- **429**：频率／并发受限，或额度不足；明确的额度错误会单独提示。
- **普通 404**：核对 Base URL 和模型 ID。
- **5xx**：中转或上游服务异常。

后端只识别有限的错误代码，返回固定中文提示，不把中转错误正文或它可能回显的密钥写入会话。
